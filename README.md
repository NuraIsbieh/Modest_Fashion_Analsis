# Modest_Fashion_Analsis# Modest Fashion Data Analysis Project

## Project Overview
This project focuses on analyzing sales performance and market trends within the Modest Fashion industry. As a Data Analyst and Software Engineer, I used data-driven insights to identify top-performing product categories and revenue drivers.

## Key Insights from the Analysis
Based on the data processed in Google Sheets:
- **Top Performer:** **Abayas** recorded the highest revenue at **$400**.
- **Market Demand:** **Hijabs** followed with a strong performance of **$330** in sales.
- **Strategic Visualization:** Developed dynamic charts and Pivot Tables to visualize revenue distribution across all categories.

## Tools Used
- **Google Sheets:** Data cleaning and Pivot Table generation.
- **Data Visualization:** Creating impactful bar charts for business reporting.
- **GitHub:** Project documentation and version control.
